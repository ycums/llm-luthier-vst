# アーキテクチャ決定記録（ADR）

仕様・構造に関する決定を、決定した時点の理由とともに残す。

## いつ書くか

- `docs/02-engine-spec.md` または `docs/03-preset-format.md` を変更するとき（必須）
- ゴールデン音源セットを変更するとき（必須）
- 外部ライブラリを追加するとき（必須）
- `docs/06-open-questions.md` の項目を resolved にするとき（必須）

## いつ書かないか

- 実装の内部的な選択で、外から見た振る舞いが変わらないもの

## ファイル名

`NNNN-短い説明.md`（連番、4桁ゼロ埋め）

## 状態

`Proposed` / `Accepted` / `Superseded by NNNN`

**採用しなかった案とその理由を必ず書くこと。** 後から同じ検討を繰り返さないための記録であり、結論だけでは役に立たない。
