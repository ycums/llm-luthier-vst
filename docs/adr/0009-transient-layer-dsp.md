# 0009. Transient / Noise 層の DSP 決定とノイズ再現性の保証範囲

- **状態**：Accepted
- **日付**：2026-09-06
- **対応Issue**：`#54`（[P1-09] Transient / Noise 層の実装）
- **前提**：`docs/adr/0008`（対象プラットフォーム＝Linux/gcc・Windows/MSVC、CIで検証）

## 1. 帯域分割方式・帯域数の暫定値（Q-004 は open のまま）

`docs/06-open-questions.md` Q-004（等間隔 / メル / バーク）は、決定に必要な観測
（アタック区間の残差がどの分割で最も素直に減るか）にレンダラが必要であり、本Issueは
そのレンダラを作る段階であるため**循環**する。Q-004 は open のまま維持し、本ADRで
暫定値を採って進める（Issue #54「依存」、AGENTS.md 第7節）。

| 事項 | 暫定値 | 理由 |
|---|---|---|
| 帯域分割方式 | **周波数等間隔**（0〜Nyquist を均等に N 分割、`[b/B, (b+1)/B]×Nyquist`） | 実装が単純・帯域数の再集計が不要。メル／バークは周波数重みの知覚根拠が必要で、その観測が未完了（Q-004） |
| 帯域数 `B` | `spectral_envelope` 配列の長さ（プリセット駆動） | プリセット形式が配列長で帯域数を表現するため固定値を持たない（docs/03）。暫定では1帯・少数帯の使用を想定 |
| ブレークポイント上限 | **設けない**（v0） | 推定コスト対プリセットサイズの観測が進むまで上限を決めない。必要なら後続Issueで上限を置く |
| 補間 `interp` | **linear / step だけ対応**。`exp` / `spline` は発生時に `PresetError` で停止 | 未知の挙動を黙って直線近似に置き換えない（AGENTS.md 第7節）。`exp` は dB 値（対数スケール）への適用意味が未整理のため保留 |

帯域制限は一極低域フィルタの差分（`band = LP@hi - LP@lo`）で行い、各帯域の包絡
（dB）を振幅スケールして加算する。時間変化する包絡はブレークポイント列を時刻
`t` で補間することで実現する（`spectral_envelope` が「時系列である」ことが core
の要件、docs/02）。

## 2. ノイズ再現性（`seed`）の保証範囲

- **採用**：C++標準ライブラリの `<random>` を使わず、**整数演算のみの自前PRNG
  （splitmix64）と、それから得る [-1,1) の一様分布**を採用する。
- **理由**：`std::normal_distribution` 等の分布クラスは C++ 標準仕様で
  実装間の出力一致を保証しておらず、コンパイラをまたいだ再現をしたい場合は自前実装
  が必要（Issue #54）。splitmix64 とその一様分布は整数シフト・乗算と IEEE double の
  round-to-nearest 変換のみで決まり、対象コンパイラ（gcc/MSVC）でビット一致する見込み。
- **保証範囲（このADRの核心）**：
  - **PRNGの整数列は対象コンパイラをまたいでビット一致する**（整数演算のみ）。
  - **ノイズ波形の「同一バイナリ／同一環境内でのビット一致」を保証し、
    コンパイラをまたいだ出力波形のビット一致は保証しない。**
    理由：帯域フィルタの浮動小数演算（`a*(x-y)`、加算・積）は IEEE ではあるが、
    FMA 融合等の最適化（例：gcc のデフォルト `-ffp-contract=fast`）によって
    最下位1ビットが揺れうるため。
  - したがって「同じ `seed` で常に同一出力（docs/02・#54）」は**同一バイナリ内の
    再現性**として成立する。CI リグレッションは同一CC（同一ジョブ）内で比較される
    ためこの保証で十分である。

## 3. サンプルレート非依存の扱い（層DSP）

- フィルタ係数と包絡の時間軸は**物理単位（Hz / sec）**で定義し、サンプル数での
  ハードコードをしない（docs/02 「サンプルレート非依存」）。
- ただし**確率的ノイズのビット一致はサンプルレート間で成立させない**。サンプルレート
  が変わればサンプル数が変わるため、同一の連続波形を再離散化したものには自然にならない。
  これは仕様の「サンプルレート非依存」を「物理的なパラメータ（時間・周波数）がサンプル
  レートの変わらずに効くこと」という解釈で満たすものであり、この解釈も ADR-0009
  の決定として記録する。

## 結果

- Transient/Noise 層の DSP（一様ノイズ＋帯域フィルタ＋時間変化包絡＋gain/duration/seed）
  を実装した。`enabled:false` のときは寄与ゼロ。
- 帯域分割は「周波数等間隔 × 配列長」の暫定値を使用。Q-004 は open のまま。
- `seed` 再現性の保証範囲＝**同一バイナリ内でビット一致**、コンパイラ間では**PRNG整数列
  のみ**保証（波形ビット一致は保証しない）、と定めた。この解釈で docs/02「同じ seed から
  常にビットレベルで同一のWAV」を実現する。
