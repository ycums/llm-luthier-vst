# セッションログ

作業中に起きた失敗・手戻りを記録する。`AGENTS.md` 第7節の「3回ルール」の根拠となる。

**スキル化やCIチェック追加の提案は、このログのエントリを引用して行う。** 根拠のない「あったら便利そう」は却下される。

```
### S-NNN
- 日付：
- 何をしようとしたか：
- 何が起きたか：
- 手戻りの規模：
- 分類：（後で集計するためのタグ。例：仕様の曖昧さ / 環境構築 / 指標の欠落 / レビュー漏れ）
- 同じ分類の過去エントリ：
```

同じ分類が3件たまった時点で、対処（スキル化 / CIチェック追加 / ドキュメント修正）を提案する。
