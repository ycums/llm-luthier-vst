# 05. 用語集

会話と実装の語彙をここに揃える。日常語として流用しないこと。

## 中核概念

**残差 / residual**
ターゲット音源とレンダ結果の差。本プロジェクトではスカラーではなく**指標ベクトル**を指す（`docs/04-metrics.md`）。「音が違う」の意味で漠然と使わない。

**フィット誤差 / fit error**
エンジンには表現能力があるが、パラメータ推定がまだ追い込めていない状態の残差。ループ1の内部で解消される。

**能力ギャップ / capability gap**
エンジンにそもそも表現する場所がないために生じる残差。ループ1では解消できず、ループ2へエスカレーションされる。**この2つの混同が最も危険な誤りである。**

**残差プロファイル / residual profile**
残差の時間・周波数方向の分布パターン。能力ギャップの所在を指し示す。

**コーパス**
ループ2の判断単位となるゴールデン音源セット。1音源で仕様改訂を判断してはならない。

**マクロ軸 / macro axis**
DAWに露出する少数の操作軸。エンジン内部パラメータ（数百）からの写像として設計される。内部パラメータそのものではない。

**到達 / arrival**
ユーザーの脳内イメージにユーザーが辿り着くこと。ループ3の目標。参照信号がないため測定できない。

## ループ

**ループ1 / フィットループ**
実行時・1音源単位・客観指標が判定。数千回回る。

**ループ2 / 仕様改訂ループ**
開発時・コーパス単位・残差プロファイルが判定。数十回。

**ループ3 / 到達ループ**
実行時・1セッション単位・人間の耳が判定。5〜10回で予算切れ。

## 技術用語

**analysis-by-synthesis**
分析結果を直接答えとせず、合成してターゲットと比較し、差を最小化する枠組み。本プロジェクトの基本姿勢。

**ヘッドレスレンダ**
GUIを介さず、プリセットからWAVを生成するCLI経路。プラグインと同一のエンジンコアを共有する。

**中間プリセット**
LLM側とバイナリ側の唯一の境界面となるJSON（`docs/03-preset-format.md`）。

**ゴールデン音源 / ゴールデンプリセット**
CIリグレッションの基準となる固定の入力。変更にはADRを要する。

**選好抽出**
ユーザーに記述させるのではなく、複数候補のA/B弁別によって意図を推定する手法。ループ3の中核。

## 意図的に使わない語

- 「良い音」「自然な音」「近い」— 指標を経由しない主観判断は本リポジトリでは無効（`AGENTS.md` 第1節）
- 「最適化」— どの目的関数のことか不明確になるため、指標名を明示する
