# luthier

ユーザーが与えた音源と「こういう感じにしたい」という意図から、シンセエンジンのパラメータを推定し、DAW上で演奏・オートメーション可能なVSTiとして提供するシステム。

推定を行うのはLLMだが、LLMは音を聴けない。したがって本プロジェクトの設計は一貫して、**主観的な「良くなった」を排し、レンダ結果の数値差分だけを判断材料にする**という制約の上に立っている。この制約はバグではなく、設計の前提である。

## 現在のフェーズ

**フェーズ0：ハーネス構築**

まだエンジンのコードは1行も書かれていない。最初に作るのは、WAVをレンダして指標を出す評価ハーネス（`docs/04-metrics.md`）である。これがないとPRのエビデンスが成立せず、以後のすべての作業が「たぶん良くなった」で進むことになる。

フェーズの遷移条件は `docs/00-vision.md` を参照。

フェーズ0の消化計画（依存関係・着手順・管理方式）は [Issue #15](https://github.com/ycums/llm-luthier-vst/issues/15) を参照。

## 読む順序
