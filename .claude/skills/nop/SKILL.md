# nop

このSkillの唯一の仕事は、自分自身のセッションのタイトルを、現在使用
しているモデルの名前に変更することであり、それ以外は一切行わない。

## 手順

1. 自分が現在使用しているモデルの人間可読な名前を確認する。
   - モデル名は環境から毎回伝えられている(例:「You are powered by
     the model named Sonnet 5. The exact model ID is claude-sonnet-5.」
     という記述がシステムリマインダーとして常に与えられる)。ここに
     書かれている人間可読名(上記例なら `Sonnet 5`)をそのまま使う。
     これはツール呼び出しなしに確認できる。
   - 万一この記述が見当たらない場合のみ、代わりに自分自身のセッション
     情報を取得するツールを呼び、返ってきたモデルIDをそのまま使う。
     - `mcp__ccd_session_mgmt__get_session` は**存在しない環境がある**
       (2026-09-07時点、2つの独立した環境で確認: `claude.ai/code` の
       リモートセッション、および本セッション自身の過去の状態。
       いずれも `ToolSearch` が該当ツールを発見できなかった)。まず
       `ToolSearch` で `get_session` を検索し、見つかったツール
       (確認済みの例: `mcp__Claude_Code_Remote__get_session`)を使う。
       ツール名は環境によって異なりうるため、ハードコードせず都度
       確認すること。
     - `session_id` にはまず `"self"` を渡す。
       `mcp__ccd_session_mgmt__get_session` では `"self"` が呼び出し
       元自身のセッションとして扱われることを確認済み(2026-09-12、
       本セッションで確認: `model: "claude-sonnet-5"` が返った)。
       別のツールで `"self"` がエラーになる場合は、`session_id` を
       省略して再試行する(`mcp__Claude_Code_Remote__get_session` は
       省略時に呼び出し元自身の情報を返すことが確認済み)。
     - モデル名(または `model` フィールドのID)がトップレベルに無い
       場合がある。返り値の構造はツールにより異なるため、
       `mcp__Claude_Code_Remote__get_session` の場合は `ccr.id` の
       ような別の場所を探す必要があった前例([[nop]] 旧版で確認済み)
       のと同様、モデル情報の格納場所も断定せず確認すること。

2. 自分自身のセッションタイトルを変更するツールを呼び、手順1で得た
   モデル名(人間可読名。取得できたのがIDのみの場合はそのID)に
   タイトルを変更する。
   - `mcp__ccd_session_mgmt__set_session_title` が使える場合はそれを
     使う(`session_id: "self"`, `title: "<モデル名>"`)。`"self"` で
     承認なしにリネームできることを確認済み(2026-09-12、本セッション
     で確認: 自動生成タイトルからの変更は承認を求められなかった)。
     ただしユーザー自身が手動でつけたタイトルの場合はアプリ側が変更
     の承認を求めることがある(アプリの仕様)。承認を求められたら
     ユーザーに確認し、拒否されたら無理に変更しない。
   - このツールが存在しない環境では、`ToolSearch` で同等のツール
     (確認済みの例: `mcp__Claude_Code_Remote__set_session_title`)を
     探して使う。このツールで自分自身をリネームする際の挙動(引数の
     指定方法・承認要否)は未確認であり、今後の実行で確認され次第
     この記述を更新すること。

3. これ以外のツール呼び出しは行わない。ファイルの読み書き、調査、
   他セッションへのメッセージ送信なども一切しない。

4. リネームが完了したら、変更後のタイトルを1行だけ出力する。前置き・
   説明・挨拶・コードブロック・その他の装飾は一切付けない。
